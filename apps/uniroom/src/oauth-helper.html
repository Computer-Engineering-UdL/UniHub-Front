🔐 OAuth Login - Workaround Temporal

⚠️ Problema Actual: El servidor retorna els tokens directament com JSON sense fer redirect a la nostra pàgina. Això impedeix que la finestra es tanqui automàticament.

Solució Temporal

Mentre el backend no faci redirect a la nostra pàgina de callback, pots utilitzar aquest bookmarklet per processar els tokens automàticament:

Opció 1: Bookmarklet (Recomanat per desenvolupadors)

Arrossega aquest botó a la barra de marcadors del teu navegador:

OAuth Token Extractor
Quan facis login amb Google, quan vegi's el JSON amb els tokens, fes clic al bookmarklet que has guardat.
Els tokens s'enviaran automàticament a l'aplicació i la finestra es tancarà.

Opció 2: Instal·lar UserScript (Per usuaris tècnics)

Instal·la Tampermonkey o Greasemonkey al teu navegador.
Crea un nou script amb el contingut del fitxer oauth-helper.js que trobaràs a src/assets/.
Configura el script perquè s'executi a @match https://api.unihub.smuks.dev/api/v1/auth/*/callback*
ℹ️ Solució Permanent: Contacta amb el equip del backend per implementar un redirect a /oauth-callback.html amb els tokens com a paràmetres de la URL. Això permetrà que tot funcioni automàticament sense necessitar cap workaround.

Per al Backend Team

Per solucionar aquest problema permanentment, el backend hauria de fer redirect a:

http://localhost:8100/oauth-callback.html?access_token=...&refresh_token=...&token_type=bearer

En lloc de retornar directament el JSON.

Consulta el fitxer OAUTH_SOLUTION.md per més detalls.
